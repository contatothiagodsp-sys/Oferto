# Moderação

## Princípios

1. **Ofertas:** só os admins e o bot postam. Nenhum membro posta oferta em tópico de oferta nem em grupo do WhatsApp.
2. **Remova primeiro, explique depois:** golpe e spam saem na hora, sem discussão no grupo.
3. **Correção é pública:** se um post estava errado, corrija no mesmo lugar em que ele saiu. Isso vale mais do que apagar em silêncio.
4. **Nada de dados pessoais:** não peça print com nome, CPF, endereço ou pedido. Para conferir uma reclamação, peça só o produto e o preço que a pessoa viu.

## Situação → ação

| Situação | Ação | Resposta pronta |
|---|---|---|
| Link de outro grupo ou divulgação | Apagar a mensagem e remover a pessoa | — |
| Alguém oferece "promoção" no privado em nosso nome | Apagar, banir e repostar a mensagem antigolpe | **R1** |
| Membro avisa que recebeu golpe no privado | Agradecer em público e reforçar o alerta | **R1** |
| "O preço está diferente" | Conferir na loja. Se mudou, responder ao post | **R2** |
| "Esse desconto é falso" | Conferir o histórico. Se a pessoa tiver razão, corrigir em público; se não, mostrar a fonte | **R3** / **R4** |
| Pedido de produto específico | Anotar como candidato; não prometer | **R5** |
| Reclamação de entrega ou troca | Indicar a loja, porque não intermediamos | **R6** |
| Discussão, ofensa ou política | Apagar e mandar 1 aviso; se repetir, remover | **R7** |
| Pergunta sobre comissão ou "vocês ganham com isso?" | Responder com transparência | **R8** |

## Respostas prontas

**R1: golpe**
```
⚠️ A Ofertô NUNCA chama ninguém no privado, nem pede Pix, pagamento, dados ou código. Se receber, é golpe: bloqueie e denuncie. Nossas ofertas só saem aqui, com link direto para a loja oficial.
```

**R2: o preço mudou**
```
Conferimos: o preço mudou depois do post (era R$ [X] às [hora]). Na BF, isso acontece rápido. Por enquanto a oferta não vale mais. Se voltar, avisamos.
```

**R3: a pessoa tinha razão sobre o desconto**
```
Você tem razão, obrigado! O histórico mostra R$ [X] em [data], abaixo do preço do post. Removemos o selo ✓ dessa oferta. Erros assim nos ajudam a manter o critério.
```

**R4: o desconto confere**
```
Conferimos: o menor preço dos últimos 90 dias foi R$ [X] (fonte: [comparador/nosso histórico]), então o preço do post está igual ou abaixo. Se você viu menor em outra data, manda o link que conferimos de novo.
```

**R5: pedido de produto**
```
Anotado! Se o [produto] aparecer com desconto real, sai no tópico de [categoria]. Ative as notificações dele.
```

**R6: problema com a loja**
```
A Ofertô só divulga a oferta; a compra é feita direto com a loja. Para entrega, troca ou reembolso, fale com o atendimento da [loja]. Se precisar, o Procon e o consumidor.gov.br também ajudam.
```

**R7: aviso de conduta**
```
Vamos manter o grupo focado em ofertas, combinado? Próxima mensagem fora das regras leva à remoção.
```

**R8: comissão**
```
Sim, os links são de afiliado: se você compra, a loja nos paga uma comissão, e o preço para você é o mesmo. É isso que mantém o grupo de graça. É por isso também que só publicamos desconto real: se a oferta for ruim, você para de confiar e nós perdemos.
```

## Ferramentas

- **Telegram:**
  - "Modo lento" de 30 s no Conversa durante a BF;
  - restringir o envio de links para membros novos, se o spam aumentar (**VERIFICAR** a opção no app atual);
  - se o spam virar rotina, pensar num bot antispam. Ele não é necessário no começo e conta execuções no n8n.
- **WhatsApp:** com grupos só de admins, não há moderação de mensagens. O risco aqui é o golpe no privado, por isso a mensagem antigolpe fica fixada e é repetida 1 vez por semana.
- **Registro:** anote cada remoção e cada correção de selo na planilha de [07-acompanhamento.md](07-acompanhamento.md). Isso mostra se o critério está falhando em alguma loja ou categoria.
